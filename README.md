# ChipWhisperer Jupyter Notebook Repository

Welcome to SCA101, NewAE's intro course for learning about power analysis using the ChipWhisperer Husky! This branch only contains labs for this course. If you're looking for other courses, try checking out other branches.

These labs are designed to be supplemented by our [SCA101 online course](https://learn.chipwhisperer.io/courses/sca101), available at [learn.chipwhisperer.io](https://learn.chipwhisperer.io).

## Getting Started

First time using ChipWhisperer? Check out these links:
* [ChipWhisperer Documentation](https://chipwhisperer.readthedocs.io/en/sca101/index.html): including background on ChipWhisperer, how to run the Jupyter server, and how to install ChipWhisperer.
* Lab 1 and Lab 2 serve as an introduction to using Jupyter and using your ChipWhipserer-Husky
* Lab 3 is the first Power Analysis related lab
* The ChipWhisperer Cheat Sheet and Jupyter Cheat Sheets showcase some helpful commands
